# 配信トロフィー

YouTubeのライブ配信で、視聴者がコメント・視聴時間・参加回数・メンバーシップに応じてトロフィーを集められる、無料のツールです。トロフィーを取ると、OBSの配信画面に演出が出ます。

- **配信者のPCは何も公開しません。** 記録サーバーは自分のCloudflare（無料枠）で動きます。
- **視聴者はGoogleログイン不要。** 共通の拡張を入れて、合言葉をチャットに1回書くだけです。
- **拡張は全配信者で共通です。** 配信者がストアに拡張を出す必要はありません（登録料・審査なし）。
- **配信のたびの作業はありません。** ライブ開始を自動で検出します。

作者：きうい（[@kiwi_dori](https://x.com/kiwi_dori)） / 配布ページ：https://kiwi-garakuta.pages.dev/stream-trophy/streamers/

## しくみ

| 役割 | 場所 | 中身 |
|---|---|---|
| 記録サーバー | 配信者ごとの Cloudflare Workers + D1 | `src/` / `migrations/` |
| 管理画面・OBS表示 | 同上 | `public/` |
| 視聴者用の拡張（共通） | 視聴者のChrome / Edge | `extension/` |

拡張は、配信の概要欄にある **`配信トロフィー: https://（あなたのサーバー）`** の1行を読み取ります。さらにそのサーバーが「この配信はいまライブ中」と答えたときだけ接続します。概要欄はチャンネルの持ち主しか書けないので、他人のチャンネルになりすますことはできません。記録はその配信者のサーバーにだけ送られ、拡張の作者や他の配信者には届きません。

## はじめてのセットアップ（10分くらい）

### 準備

1. **Windows** と **Node.js 22.12以上**：入っていなければ、セットアップ実行時にダウンロードページが開きます。
2. **Cloudflareアカウント**（無料）：https://dash.cloudflare.com/sign-up
3. **YouTube Data API キー**
   1. https://console.cloud.google.com/ でプロジェクトを作成します。
   2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を有効にします。
   3. 「認証情報」→「認証情報を作成」→「APIキー」で作成します。
   4. 作ったキーの「APIの制限」を **YouTube Data API v3** だけにします。「アプリケーションの制限」は「なし」のままにします（Cloudflareからの通信は接続元IPが一定でないため）。

   ※ OAuthクライアントやテストユーザーの設定は不要です。

### 実行

`セットアップ.bat` をダブルクリックします。

1. ブラウザでCloudflareにログインして「Allow」を押します。
2. APIキーと、自分のチャンネル（`@ハンドル` のままでOK）を貼り付けます。
3. 初回のみ、workers.devの名前を聞かれたら好きな英数字を入力します。

終わると管理画面が開きます。**`管理画面URL.txt`** に、管理画面・OBS用URL・概要欄に書く1行が保存されます。管理画面とOBSのURLは他の人に見せないでください。

### OBS

`管理画面URL.txt` の「OBS ブラウザソース」のURLを、OBSのブラウザソースに **幅1920 × 高さ1080** で追加します。背景は透明です。位置・色・大きさは管理画面の「配信用デザイン」で変えられます。

### 配信の概要欄

次の1行を配信の概要欄に入れます（公開してOKです）。YouTube Studioの「設定」→「アップロード動画のデフォルト設定」の説明に入れておくと、毎回書かずに済みます。

```
配信トロフィー: https://（あなたの名前）.workers.dev
```

視聴者には「拡張を入れるとトロフィーが集まるよ」と、拡張の配布ページ https://kiwi-garakuta.pages.dev/stream-trophy/ を案内してください。拡張を入れていない人も、コメントの実績は自動で集まります。

## 視聴者がやること

1. 拡張「配信トロフィー」をPCのChrome / Edgeに入れる。
2. 対応している配信を開くと「連携する」が出るので押す。
3. 表示された `!link 123456` をライブチャットに1回書き込む。

あとはいつも通りPCのブラウザで見るだけです。チャットに `!trophy off` と書くと記録がすべて削除され、以後は記録されません（`!trophy on` で再開）。

## トロフィーを作る

管理画面の「トロフィー条件」で、名前・アイコン・条件（コメント数、総文字数、視聴時間、参加した配信の数、メンバーシップ）を自由に追加・変更できます。

**限定イベント**を選ぶと、「決めた配信・期間に、決めた言葉を含むコメントをした人」に1回だけ付与するトロフィーになります（誕生日配信の「おめでとう」、記念配信など）。保存後に、対象の配信URL・受付期間・判定する言葉を設定します。URLを空にしておくと、受付期間中に始まったライブを自動で対象にします。

## アップデート

新しい版をダウンロードしたら、フォルダの中身を上書きして `更新.bat` をダブルクリックします。記録はそのまま残ります（`.setup-state.json` と `管理画面URL.txt` は消さないでください）。

## ローカルで試す

`ローカルで試す.bat` を実行すると、CloudflareにもYouTubeにもつながない手元のデモが開きます。

## 開発

```
npm ci
npm test                         # 拡張・Worker・イベントのテスト
python tests/e2e/mock_youtube.py # 別画面。偽のYouTube APIで通し検証する場合
```

通しの検証は `.dev.vars` に `DEMO=1` / `YOUTUBE_API_KEY=test-key` / `ADMIN_KEY=admin-test-key-0123456789` / `OVERLAY_KEY=overlay-test-key-0123456789` / `YT_API_BASE=http://127.0.0.1:8899` を書き、`npx wrangler d1 migrations apply DB --local` → `npx wrangler dev --port 8787 --test-scheduled` → `node tests/e2e/e2e_cloud.mjs` の順に実行します。拡張を実際のChromiumで通し確認するときは、続けて `python tests/e2e/browser_extension.py`（Playwrightと、ffmpegで作った `/tmp/test.mp4` が必要）を実行します。

### 任意：公開Webページ（上級者向け）

`src/web-accounts.js` は、拡張なしで自分の記録を見られる公開Webページ用のAPI（`/api/web/*`）です。使う場合は、`.setup-state.json` に `"vars": {"SITE_ORIGIN": "https://あなたのページ"}` を追加して `更新.bat` を実行し、Googleログインを使うなら `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` をCloudflareの秘密情報に登録します。設定しなければ、このAPIは無効のままです。

## 数え方

| 項目 | 内容 |
|---|---|
| コメント | 通常チャットと本文付きスーパーチャット。システム通知・合言葉・コマンドは除外。投稿IDで重複を防止 |
| 総文字数 | Unicodeのコードポイント数（空白・改行・絵文字を含む） |
| 視聴時間 | 拡張を入れたPCのブラウザで、対象ライブを再生していた時間。一時停止・広告・読み込み・シーク・アーカイブは除外。倍速でも実時間以上は加算しない。1人1タブ |
| 参加した配信 | コメントまたは視聴した配信の数 |
| メンバー | メンバーとしてコメントしたことがある |
| 限定イベント | 決めた配信・期間に、決めた言葉（例：「おめでとう」）を含むコメントをした（1回だけ） |

## APIの消費量の目安（1日の上限は1万ユニット）

- **配信中**：コメント取得1回5ユニット×20秒ごとで、1時間あたり約900ユニット。1日10時間くらいまで余裕があります。
- **待機中**：5分ごとの配信チェックで1日約600ユニット。OBSの配信用画面を開いている間は1分ごとにチェックします。
- **割当量を超えたとき**：管理画面に表示され、30分後に自動で再開します。

## プライバシーの設計

- 保存するのは、チャットに公開されているチャンネルID・表示名・メンバーかどうかと、件数・文字数・視聴時間・獲得実績だけです。**コメント本文は保存しません。**
- 視聴者のGoogleアカウントにはアクセスしません。連携は合言葉方式です。
- 重複防止用の投稿IDは3日、演出キューは1日、使われなくなった連携は180日で自動削除します。Cloudflareのログ機能はオフにしています。
- 視聴者は、拡張の「記録を削除」かチャットの `!trophy off` で全記録を削除でき、以後は記録されません（`!trophy on` か再連携で再開）。
- 管理画面・OBS用URLは長いランダムな鍵で保護しています。APIキーはCloudflareの秘密情報として保存し、画面やファイルには出しません。

## 制限

- 限定公開・メンバー限定の配信は自動検出できないことがあります。その場合は管理画面「YouTube接続」の配信URL欄に貼り、終わったら空欄に戻してください。
- スマホのYouTubeアプリ・テレビでの視聴時間は計測できません（コメントは記録されます）。
- 視聴時間は「再生していた時間」で、画面を見ていたかまでは分かりません。完全な不正対策ではありません。
- YouTube API の規定には、視聴・コメント等への報酬を禁じる条項があります（III.F.3.c）。お試し運用であることを踏まえて使ってください。
