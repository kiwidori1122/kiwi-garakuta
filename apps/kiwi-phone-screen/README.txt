きういスマホ画面 0.1.2 — Windows 11 x64

Androidスマホの画面をPCに映して、マウスやキーボードで操作したり、録画したりできます。
USBケーブルでつなぐだけで、スマホにアプリを入れる必要はありません。

1. ZIPをすべて展開してKiwiPhoneScreen.exeを起動します。
2. 初回のみ「エンジンを準備」で、scrcpy公式のWindows版（約11 MB）を取得します。
3. スマホで「USBデバッグ」をオンにして、USBケーブルでPCとつなぎます。
   やり方は画面の「はじめての方へ」に書いてあります（最初の1回だけ）。
4. 「スマホを探す」を押し、スマホに出た「USBデバッグを許可しますか？」で「許可」を押します。
5. 「接続OK」になったら「映す」を押します。

映している間は、PCのマウスでタップ・スワイプ、キーボードで文字入力ができます（右クリックは「戻る」）。
画質・通信量、スマホの音をPCで鳴らすか（Android 11以上）、見るだけにするか、
スマホ本体の画面を消すか、スリープさせないか、いつも手前に表示するかを選べます。
「録画する」にすると、終わったときに保存先へMP4で保存します（同名のファイルは上書きしません）。
終わるときは、スマホの画面のウィンドウを閉じるか「映すのをやめる」を押します。

対応：Android 5.0以上（音の転送はAndroid 11以上）。USB接続のみで、1台ずつ映します。
iPhone、Wi-Fiでの接続、複数台の同時表示、カメラの映像、全scrcpyオプションの操作には対応していません。
機種によっては、音や画面オフが使えない場合があります。

エンジンはこの配布物に含めません。初回にscrcpy 5.0.1の公式Windows版を取得し、
ZIPと中身のSHA-256を確認してから使います。スマホとの通信には、その中のadbだけを使います。
scrcpy：https://github.com/Genymobile/scrcpy
配布物に含むPython・Tkなどの通知も同梱しています。
